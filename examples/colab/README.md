# Exemples de toxicité dans Colab

Les notebooks historiques conservés ici concernent uniquement la toxicité.
Ils restent liés à leurs révisions d’origine et ne sont pas certifiés comme un
parcours public autonome de la version actuelle. Pour essayer la bibliothèque,
installer `helm-xai[ui]==0.2.0rc4` et utiliser l’exemple Python du README racine.

Les calculs d’explicabilité et les profils sont disponibles dans la bibliothèque.
Aucune nouvelle exécution Colab de ces notebooks n’est revendiquée dans cette version.
