# HELM 0.1.0a5 — bibliothèque et interface installables

Livraison préparée le 10 septembre 2026 pour un dépôt GitHub dédié, privé.

- Interface épurée incluse dans la wheel : utilisation sans Node.js.
- Commande `helm-ui` et alternative `python -m helm.ui`, ouverture automatique du
  navigateur, choix du port et du dossier de données.
- API et stockage regroupés dans `helm.ui` ; imports historiques du démonstrateur
  source conservés par des façades. Aucune base créée à l’import du module installé.
- Données d’usage enregistrées hors du dossier d’installation.
- Sources exportées dans un dépôt autonome, sans historique Git de la thèse.
- Scripts de build et de recette, métadonnées de citation et CI fournis.

Le moteur scientifique a4 est conservé. La nouvelle version conserve la séparation
par version des notes d’apprentissage. Le lot d’étude distante et ses réponses
ne sont ni incorporés ni migrés. Le package reste une alpha de recherche privée.

Les résultats des vérifications de cette livraison sont consignés dans
`docs/VALIDATION_0.1.0a5_v1_2026-09-10.md` après exécution.
