# Profils de restitution

Texte : utilisateur, modérateur, expert technique et régulateur. Le profil est
choisi par l’utilisateur et ne constitue pas une prédiction sur l’auteur du texte.

Tabulaire : `utilisateur`, `metier`, `technique`, `audit`. Les deux premiers
proposent SHAP, les deux autres SHAP et LIME. Les poids des méthodes ne sont pas
fusionnés. Ces règles sont explicites ; aucune préférence humaine apprise n’est
revendiquée pour l’extension tabulaire.
